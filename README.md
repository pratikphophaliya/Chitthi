# Chitthi — letters across generations

Families live in different scripts. Chitthi carries the letter across.

Grandparents write in Indian scripts; grandkids speak Hinglish. Chitthi reads Dadi's handwritten letter
(Sarvam Vision), translates and explains it (Sarvam Translate + Sarvam-105B), reads it aloud (Bulbul),
and turns the grandkid's spoken reply (Saaras) into a loving letter in Dadi's own script and voice.

## Run

```powershell
pip install -r requirements.txt
$env:SARVAM_API_KEY = "your_key"   # or paste it in the app
python -m streamlit run app.py
```
